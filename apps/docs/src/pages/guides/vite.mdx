# Vite [Use keltra in a Vite project]

keltra works with any Vite project: React, Vue, Svelte, or plain TypeScript. It needs Vite 5 or newer and is tested on Vite 8.

## Set up

The fastest way is `npx keltra init`: it writes `keltra.config.ts`, adds `".keltra/*.d.ts"` to your `tsconfig.app.json`, and adds `keltra()` to `vite.config.ts` for you. If you prefer to set it up by hand — or init couldn't edit one of the files — do it manually:

```ts [vite.config.ts]
import react from "@vitejs/plugin-react";
import keltra from "keltra/vite";
import { defineConfig } from "vite";

export default defineConfig({
  plugins: [react(), keltra()],
});
```

Put your settings in `keltra.config.ts` rather than passing them to the plugin:

```ts [keltra.config.ts]
import { defineConfig } from "keltra";

export default defineConfig({
  dirs: ["public"],
});
```

:::tip
The CLI (`keltra generate`) only reads `keltra.config.ts`. Keeping your settings there means the dev server and CI always agree. Options passed to `keltra()` still work and override the file.
:::

## Using the paths

```tsx [src/App.tsx]
import { assetPath } from "keltra";
import { KTImg } from "keltra/image";

export default function App() {
  return (
    <>
      <img src={assetPath("/logo.svg")} alt="Logo" />
      <KTImg src="/images/hero.svg" alt="Hero" width={480} height={240} priority />
    </>
  );
}
```

## Base path

`assetPath` and `KTImg` read Vite's `base` option, so a site served from `/repo/` gets `/repo/logo.svg` without any extra code. See [Deployment](/guides/deployment).

## Server rendering

The base path also applies when your app is rendered on the server through Vite, so server and client output match.

## Plugin reference

```ts
function keltra(options?: KeltraConfig): Plugin;
```

`options` accepts the same fields as [`keltra.config.ts`](/reference/config). They are merged over the config file, and the plugin's values win.

| Vite hook | What keltra does |
| --- | --- |
| `configResolved` | Loads `keltra.config.ts` from the project root and merges your options over it |
| `buildStart` | Generates the manifest. Runs for `vite build` and when the dev server starts |
| `configureServer` | Starts watching the asset folders (dev server only) |
| `buildEnd` | Stops the watcher |

The plugin logs through Vite's logger, only when something changed:

```text
[keltra] generated 12 asset paths
[keltra] manifest updated (13 asset paths)
```

## Requirements

- Vite 5 or newer. Tested on Vite 8.
- `vite` is an optional peer dependency of `keltra`, so you only need it when you use this plugin.
