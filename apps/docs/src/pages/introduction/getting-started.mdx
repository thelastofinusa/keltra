# Getting Started [Set keltra up in an existing project]

:::info
keltra supports Vite today. Next.js is in progress, see [Framework support](/guides/frameworks).
:::

## Quick start

Run the setup command from your project root:

:::code-group

```bash [npm]
npx keltra init
```

```bash [pnpm]
pnpm dlx keltra init
```

```bash [yarn]
yarn dlx keltra init
```

```bash [bun]
bunx keltra init
```

:::

The CLI detects your framework, asks where your assets live, installs keltra if needed, writes a `keltra.config.ts`, adds `.keltra/` to your `.gitignore`, and generates the first manifest. Add `-y` to skip the questions and accept the detected defaults. See the [CLI reference](/reference/cli) for every option.

## Manual setup

Prefer to do it yourself? These steps match what `keltra init` does.

::::steps

### Install the package

:::code-group

```bash [npm]
npm install keltra
```

```bash [pnpm]
pnpm add keltra
```

```bash [yarn]
yarn add keltra
```

```bash [bun]
bun add keltra
```

:::

### Create a config file

Tell keltra which folders hold your assets. Files in `public/` are served as-is by Vite, so that is the default.

```ts [keltra.config.ts]
import { defineConfig } from "keltra";

export default defineConfig({
  dirs: ["public"],
});
```

See [Configuration](/reference/config) for all options.

### Add the Vite plugin

```ts [vite.config.ts]
import { defineConfig } from "vite";
import keltra from "keltra/vite";

export default defineConfig({
  plugins: [keltra()],
});
```

### Include the generated types in tsconfig

```json [tsconfig.json]
{
  "include": ["src", ".keltra/*.d.ts"]
}
```

:::warning
Use `".keltra/*.d.ts"`, not just `".keltra"`. TypeScript skips folders that start with a dot when you list them by name, so the shorter form silently loads nothing and your paths stay plain strings.
:::

### Ignore the generated folder

```bash [.gitignore]
.keltra/
```

### Start your dev server

keltra generates the manifest when the server starts and keeps it up to date while it runs.

::::

## Use typed paths

```tsx [src/App.tsx]
import { assetPath } from "keltra";
import { Image } from "keltra/image";

export default function App() {
  return (
    <>
      <img src={assetPath("/logo.svg")} alt="Logo" />
      <Image src="/images/hero.png" alt="Hero" width={1200} height={600} />
    </>
  );
}
```

Both `assetPath` and `Image` autocomplete from the files in your asset folders. A path that doesn't exist fails the type check:

```ts
assetPath("/images/hreo.png");
// Error: Argument of type '"/images/hreo.png"' is not assignable to
// parameter of type '"/images/hero.png" | "/logo.svg"'.
```
